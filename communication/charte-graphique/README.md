# Charte graphique MaCity

Tout ce qu'il faut pour utiliser la marque MaCity : logos, couleurs, typographies, éléments graphiques et captures de l'app.

**Document principal : `charte-graphique-macity.pdf`** (12 pages A4). La version `charte-graphique-macity.html` est la source modifiable ; elle s'ouvre dans un navigateur et doit rester dans ce dossier (elle charge les polices et les images en chemins relatifs).

## Contenu

| Dossier | Contenu |
|---|---|
| `01-logos/svg` | Logos vectoriels : à privilégier pour l'impression, les grands formats et les graphistes |
| `01-logos/png` | Mêmes logos en PNG transparent haute définition (2x) |
| `01-logos/originaux-app` | Fichiers d'origine utilisés dans l'app et sur les stores |
| `01-logos/archive` | Ancienne identité violette (avril 2026) : ne plus utiliser |
| `02-couleurs` | `palette-macity.css` (variables CSS), `palette-macity.json`, `nuancier-macity.txt` (HEX, RVB, CMJN) |
| `03-typographies` | Inter, Geist, Geist Mono, Poppins en TTF avec leurs licences (libres, SIL Open Font License) |
| `04-elements-graphiques` | Dégradés en PNG 1920x1080, QR codes de téléchargement (PNG et SVG) |
| `05-mockups` | Captures de l'app actuelle, et de l'ancienne interface pour mémoire |
| `_apercus` | Images allégées utilisées par la charte HTML/PDF (ne pas diffuser) |
| `_sources` | Scripts qui ont généré les logos, la palette et la charte (usage interne) |

## Logos : quelle version choisir

| Fichier | Quand l'utiliser |
|---|---|
| `macity-logo-couleur-fond-sombre` | Fond sombre ou photo foncée (version principale) |
| `macity-logo-couleur-fond-clair` | Fond blanc ou clair |
| `macity-logo-blanc` | Fond rose, violet ou dégradé |
| `macity-logo-noir` | Impression une couleur, tampon, gravure |
| `macity-logo-vertical-*` | Formats carrés ou hauts (affiche, post Instagram) |
| `macity-pin-*` | Symbole seul (petits formats, carte, motif) |
| `macity-icone-app` | Avatar réseaux sociaux, favicon |

## Repères rapides

- Couleur signature : **Rose MaCity #FF1E8E**
- Base sombre : **Nuit MaCity #1A0F2E**
- Couleur des boutons dans l'app : **Magenta #E91E63**
- Police du logo : **Inter ExtraBold** (réservée au logo)
- Police de l'app : **Geist** ; supports de communication : **Poppins**

## Notes

- Les logos SVG ont été redessinés en vectoriel à partir du logo PNG officiel (texte vectorisé en Inter ExtraBold, pin repris du fichier `design/logo/app-icon.svg`). Ils se superposent à l'original.
- Les valeurs CMJN sont des conversions automatiques : à faire valider par l'imprimeur.
- Les valeurs de marque (page 2 de la charte) sont une proposition à valider.
